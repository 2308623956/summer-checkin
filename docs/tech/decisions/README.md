# 技术决策记录（ADR）

一条决策一个文件：`ADR-编号-短标题.md`。**一经记录不再改写**——要推翻它就新增一条，并在两头的"状态"里写清取代关系。

## 格式

```
# ADR-00N 标题

- 状态：已采纳 / 已取代（被 ADR-00M 取代）/ 已废弃
- 日期：YYYY-MM-DD
- 相关：涉及的其他文档

## 背景
为什么要做这个决定（当时的约束与目标）

## 决策
最终选了什么，一句话说清边界

## 被否方案
每个备选方案一段：是什么、为什么不选

## 代价与后果
这个决定带来的成本、新增的约束、以后想改要付什么

## 验证方式
怎么知道这个决定是对的（可观察的信号）
```

## 为什么记

面试时被问"为什么这么设计"，答案在这里；几个月后自己想改一个"看起来很简单"的设计时，先读它，能避免重复踩已经踩过的坑。
