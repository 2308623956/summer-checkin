Trellis完整模板
你可以直接这样用:

```
$start
$grill-me
我想实现:[一句话描述功能]
限制:
先不要写代码
先不要创建 PRD
先不要改文件
你要先把需求问清楚
请重点grill:
1.用户是谁
2.触发入口是什么
3.成功路径是什么
4.失败路径是什么
5.权限/安全边界是什么
6.哪些是MVP，哪些明确不做
7.如何验收
8.哪些现有模块可能受影响
每个问题都给你的推荐答案。
最后输出一份可以直接交给Trellis的任务说明。
```


然后:

```
请把上面grill-me 的结论交给Trellis，创建一个清晰的task/PRD.
不要扩大范围。
如果发现PRD里还有模糊点，先列出来，不要直接实现。
```

再然后:

```
continue
```
